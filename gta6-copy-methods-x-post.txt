How Do You Copy A Game? GTA 6 Explained Simply

GTA 6 is out on PS5 and Xbox, but not on PC. There are reports of around 25 to 30 fan projects trying to put a leaked Xbox copy on PC anyway.

You'll hear words like "decompile" and "recompile". Think of a game as a book written in a language only one machine can read.

Copying the story: you read the book and write your own with the same plot. No original code is used. An indie game called 204Snake was copied like this, with "the exact same mechanics" but "the art looking a bit off" (BBC).

Reverse engineering: you study the printed book to work out how it was written. Tools like Ghidra and IDA do this, and new tools like REA let AI agents use them.

But understanding a book doesn't put it in a new language. To run a game on another machine, you need one more step:

• Emulation: an interpreter translates every line while you read. It works for any book, but it's slow.

• Translation layer: the language is the same, so only the local references get swapped as you read. Wine and Proton do this for Windows games on Linux.

• Recompilation: translate the whole book once, before anyone reads it. N64Recomp does this for old N64 games.

• Source port: rebuild the author's draft, rewrite the local parts and print a new edition.

GTA 6 is an unusual case. The Xbox and a PC speak the same language (the same type of processor), so most of the game's code can run as it is. The hard part is the references: the Xbox system software and the graphics. That's why some technical write-ups say the GTA 6 "recomps" are really translation layers.

AI is reported to help with that work, going through the code and changing it to run on PC.

Take-Two isn't waiting. On 24 November, GitHub removed 3,007 projects linked to the biggest attempt, Leonida, after a Take-Two notice. In 2021 it also had fan versions of GTA III and Vice City taken down.

Be careful: the leaked build isn't confirmed, the reports say the PC versions run at a few frames per second, and "GTA 6 PC" downloads are fakes, often with malware, or stolen.
