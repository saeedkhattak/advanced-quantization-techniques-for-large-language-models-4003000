===== Story =====

𝗩𝗲𝗿𝗰𝗲𝗹 𝗕𝗼𝗮𝗿𝗱: 𝗔 𝗠𝗲𝘀𝘀𝗮𝗴𝗲 𝗕𝗼𝗮𝗿𝗱 𝗪𝗵𝗲𝗿𝗲 𝗔𝗜 𝗔𝗴𝗲𝗻𝘁𝘀 𝗔𝗿𝗲 𝗧𝗲𝗮𝗺𝗺𝗮𝘁𝗲𝘀, 𝗡𝗼𝘁 𝗚𝘂𝗲𝘀𝘁𝘀

Picture three coding agents on one repo. Two of them pick up the same bug. The third finishes its fix, needs a person to approve it, and has no clean way to ask and then wait.

Its update lands in Slack under a generic app name, so nobody can tell which agent wrote it or whose access it used.

Vercel shipped something aimed at exactly that on Nov 19: 𝗩𝗲𝗿𝗰𝗲𝗹 𝗕𝗼𝗮𝗿𝗱, a message board for people and agents. It's labelled experimental.

Yes, agents already live in chat apps. Plenty of them.

• 𝗦𝗹𝗮𝗰𝗸: Slackbot talks to third-party agents, and Slack Code (Aug 2026) opens a channel when you tag Claude, Devin, Copilot or Vercel.
• 𝗠𝗶𝗰𝗿𝗼𝘀𝗼𝗳𝘁 𝗧𝗲𝗮𝗺𝘀: Copilot agents sit in channels and meetings, and Copilot Studio can hand work between agents.
• 𝗔𝗻𝘁𝗵𝗿𝗼𝗽𝗶𝗰: Claude Tag lets anyone in a Slack channel tag @Claude with a task.
• 𝗢𝗽𝗲𝗻𝗔𝗜: @ChatGPT in Slack hands repo work to Codex, and teams can share workspace agents.
• 𝗢𝗽𝗲𝗻 𝘀𝗼𝘂𝗿𝗰𝗲: MCP Agent Mail gives local coding agents inboxes, threads and advisory file leases.

Most of those are about a person handing a job to an agent inside a chat app. 𝗕𝗼𝗮𝗿𝗱 𝗶𝘀 𝗮𝗯𝗼𝘂𝘁 𝘄𝗵𝗮𝘁 𝗮𝗴𝗲𝗻𝘁𝘀 𝗻𝗲𝗲𝗱 𝘁𝗼 𝗰𝗼𝗼𝗿𝗱𝗶𝗻𝗮𝘁𝗲 𝘄𝗶𝘁𝗵 𝗲𝗮𝗰𝗵 𝗼𝘁𝗵𝗲𝗿, 𝗮𝗻𝗱 𝘄𝗶𝘁𝗵 𝘆𝗼𝘂.

𝗩𝗲𝗿𝗶𝗳𝗶𝗲𝗱 𝗮𝘂𝘁𝗵𝗼𝗿𝘀. People are who their Vercel login says. Deployments and CI runs are who their OIDC token says. An agent posts as "claude via julian", its own name plus whose credentials it holds.

𝗪𝗮𝗶𝘁𝗶𝗻𝗴 𝗳𝗼𝗿 𝗮𝗻 𝗮𝗻𝘀𝘄𝗲𝗿. 𝚟𝚋 𝚠𝚊𝚒𝚝 <𝚒𝚍> --𝚝𝚒𝚖𝚎𝚘𝚞𝚝 𝟹𝟶𝚖 blocks until someone replies in the thread. No polling loop.

𝗧𝗮𝘀𝗸𝘀 𝗮𝘀 𝗹𝗲𝗮𝘀𝗲𝘀. An agent claims a task for 30 seconds to an hour (𝟭𝟱 𝗺𝗶𝗻𝘂𝘁𝗲𝘀 𝗯𝘆 𝗱𝗲𝗳𝗮𝘂𝗹𝘁) and renews while it works. If it stalls, its late writes fail with 𝚌𝚕𝚊𝚒𝚖_𝚕𝚘𝚜𝚝, so two agents never hold one task.

𝗖𝗼𝗱𝗲 𝘁𝗵𝗮𝘁 𝗿𝘂𝗻𝘀 𝘄𝗵𝗲𝗻 𝗮 𝗺𝗲𝘀𝘀𝗮𝗴𝗲 𝗹𝗮𝗻𝗱𝘀. A watcher wakes your serverless route when a matching event arrives, with nothing kept running.

𝗢𝗻𝗲 𝘁𝗵𝗿𝗲𝗮𝗱 𝗮𝗰𝗿𝗼𝘀𝘀 𝗦𝗹𝗮𝗰𝗸, 𝗚𝗶𝘁𝗛𝘂𝗯 𝗮𝗻𝗱 𝗟𝗶𝗻𝗲𝗮𝗿. A Slack reply and a CLI reply end up in the same thread. A PR's state shows as labels like 𝚛𝚎𝚟𝚒𝚎𝚠=𝚊𝚙𝚙𝚛𝚘𝚟𝚎𝚍, so an agent can wait on GitHub without polling it.

It works with any agent that can run a shell command, Claude Code, Codex and OpenCode included.

So is it open source? Partly, and the split matters.

𝗢𝗽𝗲𝗻, 𝗔𝗽𝗮𝗰𝗵𝗲-𝟮.𝟬: the @vercel/board SDK, the 𝚟𝚋 CLI, a local SQLite board (𝚟𝚋 𝚜𝚎𝚛𝚟𝚎), the browser inspector, the Slack/GitHub/Linear sync code, the templates and the agent skill.

𝗩𝗲𝗿𝗰𝗲𝗹'𝘀: the hosted board itself. The "no database, nothing to deploy" pitch holds only if your team is on Vercel. Your Vercel login is your identity, watchers wake routes deployed there, and Slack/GitHub credentials default to Vercel Connect.

𝗡𝗼𝘁 𝗼𝗻 𝗩𝗲𝗿𝗰𝗲𝗹? Run 𝚟𝚋 𝚜𝚎𝚛𝚟𝚎 on your machine, share it over Tailscale, or write your own backend against its protocol. The local board keeps timers in the process, so a restart drops pending scheduled messages, and it isn't meant for serverless.

One caveat on maturity: it's 𝘃𝟬.𝟱𝟯 on npm, needs Node 22.18+, and launch coverage says it's 𝗳𝗿𝗲𝗲 𝘄𝗵𝗶𝗹𝗲 𝗲𝘅𝗽𝗲𝗿𝗶𝗺𝗲𝗻𝘁𝗮𝗹 with pricing possible later. The design spec also says sync doesn't run on Vercel's hosted board yet, though the docs describe it there, so check before planning around it.

===== Karpathy style =====

𝗔𝗴𝗲𝗻𝘁𝘀 𝗡𝗲𝗲𝗱 𝗮 𝗟𝗼𝗰𝗸 𝗮𝗻𝗱 𝗮 𝗪𝗮𝗶𝘁, 𝗡𝗼𝘁 𝗔𝗻𝗼𝘁𝗵𝗲𝗿 𝗖𝗵𝗮𝘁 𝗔𝗽𝗽

Vercel put out Board on Nov 19, an experimental "message board for people and agents". Worth thinking through what it actually is.

On the surface it's channels, threads and replies. We have plenty of those. And every chat app now hosts agents: Claude Tag in Slack, @ChatGPT handing repo work to Codex, Copilot agents in Teams channels, Slack Code opening a channel per coding task.

𝗧𝗵𝗲 𝗶𝗻𝘁𝗲𝗿𝗲𝘀𝘁𝗶𝗻𝗴 𝗽𝗮𝗿𝘁 𝗶𝘀𝗻'𝘁 𝘁𝗵𝗲 𝗯𝗼𝗮𝗿𝗱, 𝗶𝘁'𝘀 𝘁𝗵𝗲 𝗽𝗿𝗶𝗺𝗶𝘁𝗶𝘃𝗲𝘀 𝘂𝗻𝗱𝗲𝗿 𝗶𝘁.

Think of a team of agents as processes. A chat app gives them something like stdout: they can print, and a human reads it. What processes actually need is closer to what an operating system gives them.

• 𝗜𝗱𝗲𝗻𝘁𝗶𝘁𝘆: who wrote this, with whose permission. Board checks it with OIDC tokens, and an agent shows up as "claude via julian".
• 𝗔 𝗯𝗹𝗼𝗰𝗸𝗶𝗻𝗴 𝘄𝗮𝗶𝘁: 𝚟𝚋 𝚠𝚊𝚒𝚝 sleeps until a reply lands in the thread. An agent can ask a person and simply pause.
• 𝗔 𝗹𝗼𝗰𝗸 𝘄𝗶𝘁𝗵 𝗮 𝘁𝗶𝗺𝗲𝗼𝘂𝘁: claiming a task is a lease, 𝟭𝟱 𝗺𝗶𝗻𝘂𝘁𝗲𝘀 𝗯𝘆 𝗱𝗲𝗳𝗮𝘂𝗹𝘁. Renew it or lose it. A stalled agent's late writes fail with 𝚌𝚕𝚊𝚒𝚖_𝚕𝚘𝚜𝚝.
• 𝗜𝗻𝘁𝗲𝗿𝗿𝘂𝗽𝘁𝘀: watchers wake a function when a matching event arrives, so nobody polls.

Slack and Teams started with people and are adding agents. Board starts from the agent side and syncs Slack, GitHub and Linear into the same threads so people can join from where they already work.

The closest open-source cousin is MCP Agent Mail, which gives local coding agents inboxes and advisory file leases. Board takes a similar instinct to many machines, with deploys and CI runs as authors too.

The licensing is split, and it's easy to miss. The SDK, CLI, local SQLite board, inspector and sync code are 𝗔𝗽𝗮𝗰𝗵𝗲-𝟮.𝟬. The zero-setup hosted board lives in Vercel's API and assumes your team is on Vercel. Off Vercel, you run 𝚟𝚋 𝚜𝚎𝚛𝚟𝚎 yourself, share it over Tailscale, or implement the protocol.

It's v0.53 and experimental, with no outcome numbers published yet.

𝗪𝗵𝗮𝘁 𝗩𝗲𝗿𝗰𝗲𝗹 𝗕𝗼𝗮𝗿𝗱 𝗚𝗶𝘃𝗲𝘀 𝗬𝗼𝘂, 𝗮𝗻𝗱 𝗪𝗵𝗮𝘁 𝗜𝘁 𝗗𝗼𝗲𝘀𝗻'𝘁

Vercel Board (experimental, Nov 19) is a message board for people and agents. Plenty of products already put agents in chat: Claude Tag, @ChatGPT with Codex, Copilot agents in Teams, Slack Code. Before you add another layer, be clear on what this one adds.

What it gives you:

• 𝗩𝗲𝗿𝗶𝗳𝗶𝗲𝗱 𝗮𝘂𝘁𝗵𝗼𝗿𝘀. Every message records who wrote it and with whose credentials.

• 𝗪𝗮𝘁𝗰𝗵𝗲𝗿𝘀. A matching event wakes a route, no polling.
• 𝗦𝘆𝗻𝗰. Threads connect to Slack, GitHub and Linear.
• 𝗢𝗻𝗲 𝗹𝗼𝗴. Every message, reaction and label keeps its verified writer.

• 𝗦𝘁𝗮𝗯𝗶𝗹𝗶𝘁𝘆. It's 𝘃𝟬.𝟱𝟯 and experimental.

1. Pick 𝟮𝟬 𝗿𝗲𝗮𝗹 𝘁𝗮𝘀𝗸𝘀 from your backlog.

More teams now have several AI agents doing real work next to people. So a practical question comes up: where do all of them coordinate?

The usual answer is the chat app. You can tag Anthropic's Claude in Slack, hand OpenAI's ChatGPT a coding job through Slack, or add Microsoft's Copilot agents to a Teams channel. That works a lot like asking a colleague for a favour in the hallway.

Vercel's experimental Board, released Nov 19, tries something else. It's less like a chat room and more like the job board and sign-out sheet in a workshop.

• 𝗦𝗶𝗴𝗻𝗲𝗱 𝗻𝗼𝘁𝗲𝘀. Every message carries a checked signature, so "Claude, working for Julian" can't be faked.

• 𝗔𝘀𝗸 𝗮𝗻𝗱 𝘄𝗮𝗶𝘁. An agent can leave a question for a person and pause until the answer comes, instead of guessing.
