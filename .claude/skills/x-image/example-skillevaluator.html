SkillEvaluator is an open-source tool that checks AI agent skills and measures their effect on task results: start with quality checks, then compare live runs with and without a skill.

Agent skills are folders of instructions and supporting files defined by the Agent Skills specification. SkillEvaluator is part of the NVIDIA Verified Skills pipeline.

Three-tier overview

TierQuestion
Tier 1: ValidationIs the skill safe and well-formed?
Tier 2: DeduplicationDoes guidance repeat or overlap?
Tier 3: Live EvaluationDoes the skill help the agent?

Bring skill evaluation to your repository

Check changed skills in GitHub or GitLab with quality checks, SkillSpector security scanning and reports. Choose folders and thresholds; no evaluator code to import.

GitHub guided setup: run inside your checked-out repository:

pip install --upgrade skillevaluator
skillevaluator ci init
