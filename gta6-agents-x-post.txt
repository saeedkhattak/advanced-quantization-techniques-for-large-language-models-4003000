1. STORY
=====================================================

GTA 6 Is The Test Case For What Coding Agents Are Good At

GTA 6 came out on PS5 and Xbox Series X|S on November 19. There's no PC version and no PC date.

About a day after launch, a hacking group called CyberLeek put a stolen Xbox build of the game online, according to The Decoder. The main executable leaked a few days later.

Less than four days after that, one tracking site listed about 40 projects trying to get it running on PC. Nearly half can boot it. The furthest is rated more than 90 percent of the way to playable, on the site's own scale.

On November 26, footage showed an unofficial PC multiplayer mode. Several players, cars, voice chat, 25 to 30 fps. The tracker's operator says it's real.

Most coverage treats this as gaming news. I think the more useful story is about the tools.

The Decoder names Claude Code as one of the tools driving the pace. The work being handed to agents is reverse engineering, compatibility layers and recompilation.

That's not glamorous work. It's reading a binary nobody documented, working out what each function does, and writing the glue that makes console calls behave on a PC. Lots of small, checkable steps. That's exactly the shape of task agents have been getting good at.

There's one detail that matters a lot here. The Xbox Series X runs a custom AMD Zen 2 chip, which is x86-64, the same instruction set as a PC. So nobody has to translate the CPU code itself. The hard part is the console-specific layer around it, which is mostly glue code.

This didn't come from nowhere. Through 2026, fans have been turning old Xbox 360 games into native PC builds with static recompilation tools like XenonRecomp and the ReXGlue SDK. Blue Dragon, King Kong and the cancelled GoldenEye 007 port all got this treatment, and some of those projects were written largely with Claude.

For builders, the honest lesson from those projects is that the agent wrote a lot of code on top of frameworks, runtimes and reverse-engineering work humans had already done. The agent sped up the last mile. It didn't replace the first one.

For the industry, the business question is real. GTA V took about 19 months to reach PC. Red Dead Redemption 2 took about a year. A console-first window depends on porting being slow and expensive. If the labour gets cheap, the window gets shorter whether the publisher wants it to or not.

Now the limits. There's no finished PC version anyone can play. The most stable builds are incomplete, sit in closed groups, or need real know-how, and some reports say builds still stop at the settings and legal screens. The progress numbers come from one unnamed tracker's own scale. And every one of these ports is built on stolen files, which makes them illegal. Take-Two has already had GitHub remove one project and more than 3,000 forks.

So the question isn't whether this GTA 6 port finishes. It's how much a release window is worth when the porting work it relies on keeps getting cheaper.

2. KARPATHY STYLE
=====================================================

Coding Agents Vs Release Windows

Reading about the GTA 6 PC ports and I keep coming back to the mechanism, not the game.

Quick facts. GTA 6 is out on PS5 and Xbox Series X|S since November 19, no PC version. An Xbox build leaked about a day after launch, the executable a few days later. Within four days a tracker listed about 40 port projects, nearly half booting on PC. On November 26 there was footage of unofficial multiplayer at 25 to 30 fps. The Decoder names Claude Code as one of the tools doing a lot of the work.

The interesting part isn't that a big game leaked. Games leak. It's which part of the job got faster.

Porting a console game is mostly not clever work. It's patient work. You have a binary with no docs. You find a function, guess what it does, check the guess, name it, move on. Then thousands of small shims so that what the console expects to exist exists on a PC.

A decent analogy is translating a huge legal contract written in a dialect nobody publishes a dictionary for. No single sentence is hard. There are just a million of them, and each one can be checked against the rest.

That's close to the ideal task for an agent. Narrow steps, fast feedback (does it boot, does it crash here), and a loop you can run all night.

It helps that the Xbox Series X uses an AMD Zen 2 CPU, x86-64 like a PC. No instruction set to translate. What's left is mostly the glue layer, which is the boring part, and boring is where agents do well.

The precedent is already there. Xbox 360 static recompilation took off this year with XenonRecomp and ReXGlue, and some of those ports were written largely with Claude. But the developers were clear that the frameworks, runtimes and prior reverse engineering came from people. The agent sat on top.

Caveats, and they're real. No public playable PC build exists. Progress is rated on one unnamed tracker's own scale. Some reports say builds still stop at the settings screen. It's all built on stolen files and illegal, and Take-Two already had GitHub pull one project and over 3,000 forks.

What I'd actually want to see: a clear log of which steps the agent did, which a human did, and how long each took. That would tell us far more about agents than any benchmark.

Notes On AI Agents And The GTA 6 PC Ports

On the tools, the article says "AI coding tools like Anthropic's Claude Code are driving that pace." The tasks it lists are "reverse engineering, compatibility layers, and recompilation."

Two things I find worth paying attention to.

First, the CPU. The Xbox Series X uses a custom AMD Zen 2 chip, x86-64. That's the same instruction set as a PC, so this isn't the Xbox 360 problem of translating PowerPC code. It's mostly replacing console-specific APIs and plumbing. That's a lot of repetitive glue code, which is the kind of work agents are good at grinding through.

Second, the precedent. 2026 already had a wave of Xbox 360 games recompiled to native PC code with XenonRecomp (MIT licensed) and the ReXGlue SDK. Blue Dragon, King Kong, GoldenEye 007. Some were written largely with Claude, and one developer was explicit that the framework, runtime, renderer and earlier reverse engineering came from other people.

Things to be careful about:

• No finished, public, playable PC build exists, according to the article.
• "More than 90 percent of the way to playable" is the tracker's own rating, and the tracker isn't named.
• Other reports say some builds only reach the settings and legal screens.
• The article doesn't say which steps the agents did versus humans, or name the groups.
• These ports use stolen files. Take-Two had GitHub remove the first project and more than 3,000 forks.

Also worth noting: fake "full build" downloads have been carrying malware. Don't download any of it.

4. SWYX STYLE
=====================================================

Agent-Assisted Porting Is Becoming A Category

Call it agent-assisted porting. Take a console binary, point a coding agent at it, and let it grind through the reverse engineering and glue code until the thing runs on PC.

It had a quiet year and then a very loud week.

Where it stands right now:

• Xbox 360 static recompilation: XenonRecomp, then the ReXGlue SDK. Old PowerPC games turned into native PC code. Blue Dragon, King Kong and GoldenEye 007 ports shipped this year, some written largely with Claude.
• Switch ports: a Link's Awakening fan port was reportedly built mostly with Claude.
• Live console games: GTA 6. Out November 19 on PS5 and Xbox Series X|S, leaked about a day later. Within four days of the executable leak, one tracker counted about 40 projects, nearly half booting on PC. Multiplayer footage at 25 to 30 fps by November 26.

The GTA 6 case is a different class of target. It's not a 20-year-old game nobody sells. It's the biggest release of the year, still inside its console-only window.

It's also an easier technical target than it sounds. Xbox Series X runs AMD Zen 2, x86-64, same as a PC. No CPU translation. The work is the API and system layer, which is glue code at scale.

The Decoder names Claude Code as one of the tools behind the pace.

The caveats are big. No public playable build. Progress numbers come from one unnamed tracker. Some builds reportedly still stop at the settings screen. It's all stolen files, and Take-Two got GitHub to remove a project and more than 3,000 forks.

My take: console-first windows were priced on the assumption that porting takes a team a year. GTA V took about 19 months to reach PC, RDR2 about a year. Agents don't remove the legal moat, but they're eating the labour one. Expect publishers to rethink staggered launches, or ship PC on day one.

5. HAMEL HUSAIN STYLE
=====================================================

What The GTA 6 Ports Do And Don't Tell Us About Agents

People are going to read the GTA 6 PC port story as "AI can port anything now." The evidence is narrower than that.

What the reporting gives you:

• A real-world, time-boxed task. GTA 6 hit PS5 and Xbox Series X|S on November 19, an Xbox build leaked about a day later, the executable a few days after.
• A speed signal. About 40 projects on one tracker less than four days after the executable leak, nearly half booting on PC.
• One concrete output. Footage on November 26 of unofficial multiplayer: several players, vehicles, voice chat, 25 to 30 fps, verified by the tracker operator.
• A named tool. The Decoder says Claude Code is one of the tools driving the pace, on reverse engineering, compatibility layers and recompilation.

What it doesn't give you:

• Any split between agent work and human work.
• A baseline. How long would the same teams take without agents?
• A shared definition of done. "90 percent playable" is the tracker's own scale. Some builds reportedly stop at the settings screen.
• Failure data. We see the projects that boot, not the ones that stalled.

Context matters for reading the speed. Xbox Series X is x86-64, like a PC, so there's no CPU translation step. And the 2026 Xbox 360 ports built with Claude sat on top of frameworks and reverse engineering humans had already done.

If you wanted to measure this properly on a game you're allowed to touch:

1. Pick a fixed set of tasks: name 200 functions, stub 50 system calls, get to the title screen.
2. Have a human team do it without agents and log the hours.
3. Run the same tasks with an agent and log hours plus human interventions.
4. Read the traces. Where did the agent guess wrong, and how long did catching it take?

That would tell you what agents are actually good at here.

One more limit: these ports are built on stolen files and are illegal. Take-Two already had GitHub remove a project and more than 3,000 forks.

6. ETHAN MOLLICK STYLE
=====================================================

When Copying Gets Cheap, Does Waiting Still Work?

For decades, big games came out on consoles first and on PC much later. GTA V took about 19 months. Red Dead Redemption 2 took about a year.

That gap was partly strategy and partly just hard work. Moving a game to new hardware is slow, expert labour.

GTA 6 came out on PS5 and Xbox Series X|S on November 19. An Xbox build leaked about a day later, according to The Decoder, and the main executable a few days after that.

Within four days of that leak, one tracking site counted about 40 projects trying to run it on PC, nearly half of which could boot it. By November 26 there was footage of an unofficial online mode with several players driving around at 25 to 30 frames per second.

The Decoder says AI coding tools like Claude Code are a big reason for the speed.

Think of it like moving into a house where every plug is a slightly different shape. The house is fine. You just need hundreds of adapters. Making adapters is tedious, not brilliant, and it turns out AI agents are very good at tedious.

It helps that the Xbox and a PC use the same kind of processor, so the job is mostly those adapters.

The evidence cuts both ways. On one side, this kind of agent-built port already worked this year for older Xbox 360 games. On the other, no one has a finished, playable PC version of GTA 6. Progress is measured by one unnamed tracker, and some builds reportedly stop at the settings menu. And it's all built on stolen files, which is illegal. Take-Two had GitHub remove one project and more than 3,000 copies of it.

What we know is that the slow part got faster. We don't yet know by how much, or how much humans still did.

If the work that made release windows possible is getting cheap, what other business models were quietly built on "this takes a lot of skilled people a long time"?
