===== 1. STORY =====

𝗬𝗼𝘂𝗿 𝗖𝗼𝗱𝗶𝗻𝗴 𝗔𝗴𝗲𝗻𝘁 𝗡𝗲𝗲𝗱𝘀 𝗨𝗽𝗱𝗮𝘁𝗲𝘀 𝗡𝗼𝘄, 𝗡𝗼𝘁 𝗝𝘂𝘀𝘁 𝗬𝗼𝘂𝗿 𝗟𝗮𝗽𝘁𝗼𝗽

For years the ritual was Windows Update. Restart, wait, carry on with the latest fixes.

Now there's a second thing that goes stale: your coding agent.

Its knowledge stops at its training date. And the web keeps shipping. New CSS, new HTML elements, new browser APIs, every few weeks.

So the agent falls back on what it saw most, which is old code. Google's Chrome team put it plainly in the README of their new project: "𝘓𝘓𝘔 𝘵𝘳𝘢𝘪𝘯𝘪𝘯𝘨 𝘥𝘢𝘵𝘢 𝘤𝘰𝘯𝘵𝘢𝘪𝘯𝘴 𝘷𝘢𝘴𝘵 𝘢𝘮𝘰𝘶𝘯𝘵𝘴 𝘰𝘧 𝘭𝘦𝘨𝘢𝘤𝘺 𝘤𝘰𝘥𝘦."

That project is 𝗠𝗼𝗱𝗲𝗿𝗻 𝗪𝗲𝗯 𝗚𝘂𝗶𝗱𝗮𝗻𝗰𝗲. It's a set of skills, basically instruction packs, that you plug into Claude Code, Codex, Gemini, Copilot, Cursor and others. When the agent builds a web feature, it looks up the modern way first.

It covers 𝟮𝟱𝟬 𝘄𝗲𝗯 𝗳𝗲𝗮𝘁𝘂𝗿𝗲𝘀 and 𝟮𝟬𝟯 𝗿𝗲𝗮𝗹 𝘂𝘀𝗲 𝗰𝗮𝘀𝗲𝘀, from popovers and dialogs to passkeys, safe HTML handling and Temporal for dates. It also checks Baseline data, so it knows which features browsers actually support today.

What do you miss if your agent never gets this kind of update?

• 𝗕𝗶𝗴𝗴𝗲𝗿, 𝘀𝗹𝗼𝘄𝗲𝗿 𝘀𝗶𝘁𝗲𝘀: it pulls in old libraries and polyfills for things the browser now does natively
• 𝗦𝗲𝗰𝘂𝗿𝗶𝘁𝘆 𝗴𝗮𝗽𝘀: older ways of inserting HTML are an easy route for XSS, and there's a newer Sanitizer API for that
• 𝗧𝗲𝗰𝗵 𝗱𝗲𝗯𝘁 𝗼𝗻 𝗱𝗮𝘆 𝗼𝗻𝗲: brand-new code that's already a generation behind

The Chrome team's own evals show the gap. With the guidance, pass rates rose by 𝟮𝟳 𝘁𝗼 𝟯𝟲 𝗽𝗲𝗿𝗰𝗲𝗻𝘁𝗮𝗴𝗲 𝗽𝗼𝗶𝗻𝘁𝘀. Claude Code went from 𝟱𝟳% 𝘁𝗼 𝟴𝟴% in one run. These are 𝘁𝗵𝗲 𝘁𝗲𝗮𝗺'𝘀 𝗼𝘄𝗻 𝘁𝗲𝘀𝘁𝘀, 𝗼𝗻 𝘁𝗵𝗲𝗶𝗿 𝗼𝘄𝗻 𝗱𝗲𝗺𝗼 𝗮𝗽𝗽𝘀, so treat them as a strong signal, not proof.

Some honest caveats.

So the skill itself needs updating, which is the point: run 𝚗𝚙𝚡 𝚖𝚘𝚍𝚎𝚛𝚗-𝚠𝚎𝚋-𝚐𝚞𝚒𝚍𝚊𝚗𝚌𝚎@𝚕𝚊𝚝𝚎𝚜𝚝 𝚞𝚙𝚍𝚊𝚝𝚎, or switch on auto-update in Claude Code. ===== 2. KARPATHY STYLE =====

𝗬𝗼𝘂𝗿 𝗔𝗴𝗲𝗻𝘁 𝗛𝗮𝘀 𝗮 𝗞𝗻𝗼𝘄𝗹𝗲𝗱𝗴𝗲 𝗗𝗮𝘁𝗲, 𝗮𝗻𝗱 𝘁𝗵𝗲 𝗪𝗲𝗯 𝗗𝗼𝗲𝘀𝗻'𝘁 𝗪𝗮𝗶𝘁

Every model has a training cutoff. Past that date it's guessing, and when it guesses it reaches for whatever it saw most often.

On the web, what it saw most often is old code. Years of jQuery-era answers outweigh the handful of examples of a CSS feature that shipped last spring.

𝗧𝗵𝗲 𝗶𝗻𝘁𝗲𝗿𝗲𝘀𝘁𝗶𝗻𝗴 𝗽𝗮𝗿𝘁 𝗼𝗳 𝗖𝗵𝗿𝗼𝗺𝗲'𝘀 𝗠𝗼𝗱𝗲𝗿𝗻 𝗪𝗲𝗯 𝗚𝘂𝗶𝗱𝗮𝗻𝗰𝗲 𝗶𝘀 𝘁𝗵𝗮𝘁 𝗶𝘁 𝘁𝗿𝗲𝗮𝘁𝘀 𝘁𝗵𝗶𝘀 𝗮𝘀 𝗮 𝗱𝗮𝘁𝗮 𝗽𝗿𝗼𝗯𝗹𝗲𝗺, 𝗻𝗼𝘁 𝗮 𝗺𝗼𝗱𝗲𝗹 𝗽𝗿𝗼𝗯𝗹𝗲𝗺. Don't retrain anything. Hand the agent a short, current guide at the moment it writes the code.

I think of it like a car's sat-nav. The engine is fine. The maps are three years old, so it keeps sending you down a road that's now closed. You don't buy a new car, you update the maps.

The guides are tuned with evals, and the team prunes advice the models already get right, to save tokens. Their own numbers show a 𝟮𝟳 𝘁𝗼 𝟯𝟲 𝗽𝗼𝗶𝗻𝘁 jump in pass rates across Claude Code, Codex and Antigravity. Those are 𝘁𝗵𝗲𝗶𝗿 𝘁𝗲𝘀𝘁𝘀 𝗼𝗻 𝘁𝗵𝗲𝗶𝗿 𝗱𝗲𝗺𝗼 𝗮𝗽𝗽𝘀, so imo the direction matters more than the exact size.

The catch is that the maps now need updating too. The project hit v1.0.0 on 10 November after almost 200 releases since May. A stale skill is just a newer kind of stale.

What it doesn't give you:

• 𝗣𝗿𝗶𝘃𝗮𝗰𝘆 𝗯𝘆 𝗱𝗲𝗳𝗮𝘂𝗹𝘁. Telemetry is on until you set 𝙳𝙸𝚂𝙰𝙱𝙻𝙴_𝚃𝙴𝙻𝙴𝙼𝙴𝚃𝚁𝚈=𝟷.

How to check whether it helps on your code:

1. Pick 10 real tickets from your backlog that touch UI: a modal, a form, a date picker, some untrusted HTML.
2. Run your agent on them without the skill and save the output.
3. Install it, run the same tickets again, and keep everything else the same.
4. Diff the two. Count libraries added, bundle size, and anything that sets HTML directly.
5. Read the agent's traces to see whether it actually looked the guide up, or just ignored it.

===== 6. ETHAN MOLLICK STYLE =====

𝗜𝘀 "𝗔𝗴𝗲𝗻𝘁 𝗨𝗽𝗱𝗮𝘁𝗲" 𝘁𝗵𝗲 𝗡𝗲𝘄 𝗪𝗶𝗻𝗱𝗼𝘄𝘀 𝗨𝗽𝗱𝗮𝘁𝗲?

Most of us know the routine. Your computer nags you to update, you grumble, you restart, and it's patched against the latest problems.

AI coding agents have a similar problem, but it's less visible. They learn from a snapshot of the internet, and the snapshot gets older every day. When they build a website, they often use methods that were standard years ago.

Imagine hiring a builder who learned the trade in 2015 and has never read a new building code since. The house stands, but it uses old materials and misses newer safety rules.

Google's Chrome team just released a fix for websites: 𝗠𝗼𝗱𝗲𝗿𝗻 𝗪𝗲𝗯 𝗚𝘂𝗶𝗱𝗮𝗻𝗰𝗲, a free add-on that gives agents an up-to-date rulebook for the web. Their tests show agents passing 𝗿𝗼𝘂𝗴𝗵𝗹𝘆 𝟯𝟬 𝗽𝗲𝗿𝗰𝗲𝗻𝘁𝗮𝗴𝗲 𝗽𝗼𝗶𝗻𝘁𝘀 𝗺𝗼𝗿𝗲 of their tasks with it.

There are things to weigh. Those tests were run by the makers themselves. The add-on collects anonymous usage data unless you switch it off. And it only covers how browsers work, not every tool a developer uses.

What we do know is that an agent is only as current as what it's been told. If nobody updates it, it quietly falls further behind every month, and the code it writes shows it.
