𝗙𝗼𝗿 𝗹𝗲𝗮𝗿𝗻𝗲𝗿𝘀: paste the file into ChatGPT, Claude or Gemini, or drop the folder into a coding agent's skills folder, and say "teach me X". Good for things you think you understand until someone asks.

𝗙𝗼𝗿 𝗯𝘂𝗶𝗹𝗱𝗲𝗿𝘀: it's a clean example of a skill that is all behaviour and no code. Every rule is short and testable.

Is it new? Not as an idea. ChatGPT Study Mode, Gemini Guided Learning and Claude's learning mode all teach by asking questions. What's different here is a plain, strict rulebook you can read in five minutes and run on any model.

One caveat: there's no evaluation in the repo showing it teaches better. It's instructions, and how well a model follows them will vary. People have already opened pull requests for a transcript checker, an explain-first mode and a market-making simulator.
